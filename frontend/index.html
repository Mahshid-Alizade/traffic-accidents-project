Available Tools

The platform provides analytical tools for exploring accident statistics, population data, and regional information across Germany.

Accident Filter

Search accident records using year, region and accident criteria.

Accident Counter

Count accidents for selected regions and years.

Accident Rate

Rank regions by accident rate per 100,000 inhabitants.

First Year

Discover the first year a specific accident category appeared.

Population Explorer

Explore population statistics by region and year.

Region Explorer

Search AGS codes, region names and geographic information.

Dataset Metadata

View dataset descriptions, sources, licenses and coverage.
